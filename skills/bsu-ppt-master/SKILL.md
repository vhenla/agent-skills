# BSU 讲话稿转 PPT（基于 `ppt-master` 与自包含原生模板）

本 skill 将白俄罗斯国立大学（BSU）原生 PPTX 模板与项目级制作约束打包为跨 Agent 通用的自包含工作流，依赖 `ppt-master` skill 执行原生 PPTX 编辑与导出。

## 内置原生模板（自包含资源）

所有模板文件均内置于本 skill 目录的 `resources/` 下，**禁止**引用外部硬盘路径，也**禁止**自行另建无模板版本：

- **默认主模板**：[PPT模板1.pptx](./resources/PPT模板1.pptx)（16:9，23 页示例与 19 种原生版式；第 17–18 页含深蓝/白色通用图标库，第 19–20 页含法学院 Faculty of Law 等 BSU 各学院信息图素材）
- **补充模板 2**：[PPT模板2.pptx](./resources/PPT模板2.pptx)（16:9，2 页示例与 11 种原生版式，可作为模板 1 的样式与素材补充）
- **补充模板 3**：[PPT模板3.pptx](./resources/PPT模板3.pptx)（16:9，2 页示例与 11 种原生版式，可作为模板 1 的样式与素材补充）

> 始终保持 `resources/` 内的原始模板文件及用户提供的讲话稿/课程资料原样，所有编辑仅在模板副本中进行。

## 执行步骤

### 1. 前置检查：`ppt-master` 依赖检测与引导
在安装配置或首次执行本 skill 前，先检查当前 Agent 环境中是否已安装 `ppt-master` skill：
- **已在当前环境可用**：直接进入下一步。
- **当前环境未安装，但本机其他 Agent / 常见技能目录中已存在 `ppt-master`**（如其他已配置的 skills 目录或本地 `ppt-master` 仓库中的 `skills/ppt-master`）：向用户说明已找到的现有副本位置，**询问用户是否需要将其软链接（symlink）到当前 Agent 的技能目录**，获确认后再执行，禁止未经同意擅自改动目录。
- **本机未检测到 `ppt-master`**：向用户说明本 skill 依赖 `ppt-master`（`hugohe3/ppt-master`），**询问用户是否需要协助安装**（例如通过 `npx skills add hugohe3/ppt-master` 或克隆仓库并配置环境），待用户确认并完成安装后再继续生成 PPT。

### 2. 读取并梳理输入资料
- 兼容用户附带的 `.md`、`.docx` 或直接粘贴的讲话稿/课程文本。
- 若输入为 `.docx`，先完整提取正文、标题层级与核心论点：环境提供 Office 技能（如 `office` / `office-docx`）时可按需调用，否则直接使用 `ppt-master` 自带工具或本地 Python（如 `python-docx` / `zipfile`+XML / `pandoc`）解析。
- 根据讲话稿逻辑规划合理的页面结构（封面、目录/结构导览、分节过渡、核心内容页、总结/致谢页等）。

### 3. 加载 `ppt-master` 并按固定路由执行
- 制作、修改或美化 PPT 时，**先加载 `ppt-master` skill**，按其完整性检查、路由规则及所选工作流执行。
- 需要 Office 读取、编辑、渲染或格式转换能力时：若当前宿主环境已提供 `office` / `office-pptx` 等专用技能则按需加载配合；若无此类技能，则直接使用 `ppt-master` 自带脚本及本地 Python / LibreOffice 工具链完成。
- 使用现有 PPTX 模板填充新内容时，依照 `ppt-master` 的路由规则选择 **`Edit Native PPTX`**，读取并执行 `workflows/edit-native-pptx.md`；仅在用户明确要求创建可复用模板工作区时选择 `Create Template`。
- **禁止**将原生模板仅作为视觉参考后，通过自由设计或整页重绘替代其母版与版式。

### 4. 模板读取、复用与保真约束
- 制作前先读取并检查 [PPT模板1.pptx](./resources/PPT模板1.pptx)，保留其母版、版式、主题、配色、字体及视觉风格；在模板副本中填充内容，按需复用其原生页面、版式与内置图标/学院信息图素材。
- 按需读取 [PPT模板2.pptx](./resources/PPT模板2.pptx) 和 [PPT模板3.pptx](./resources/PPT模板3.pptx)，将其可用样式、布局或视觉素材补充整合到基于模板 1 的作品中。
- **模板约束优先级最高**：`ppt-master` 中的可选模板或自由设计默认项必须服从本 skill 约束。遇到模板缺失、读取失败或保真问题时，先说明具体问题并向用户确认处理方式，禁止擅自更换模板或交付无模板版本。

### 5. 内容与视觉硬性要求（覆盖 `ppt-master` 默认项）
1. **PPT 中不要出现 `Source`**：全篇所有页面均严禁添加 `Source`、来源标注、出处页脚或类似角标文字。
2. **样式丰富、视觉美观**：
   - 避免单调的纯文字项目符号列表堆砌。
   - 在严格遵循 BSU 模板配色、字体与母版规范的前提下，根据讲话稿内容灵活运用模板 1 的多样化版式与内置图标/学院信息图，并按需融合模板 2、3 中契合的样式素材（如封面页、章节过渡页、分栏对比、卡片/要点矩阵、流程/时间轴、数据/金句强调页），保证版面层次分明、美观大方。
3. **清理未使用的模板素材页**：最终导出的模板副本中，移除未使用的空白示例页、占位文本（如 `Text`）及图标/学院信息图目录页（如 `Icons`、`Infographics for faculties`）。

### 6. Python 运行环境约定
- 由 Agent 自动探测并使用当前环境中 `ppt-master` 对应的 Python / 虚拟环境（遵循 `ppt-master` skill 自身的环境检查与配置）。
- 对于依赖 `PATH` 查找 Python 的子进程，在该次调用中将探测到的虚拟环境 `bin` 目录置于 `PATH` 首位。

### 7. 文件保存与交付前自检
- 项目过程文件与最终成果均保存在当前项目工作区中，按所选工作流在当前项目内的 `exports/` 目录另存最终可编辑 `.pptx`；保持原始模板及课程/讲话稿资料原样。
- 交付前按工作流完成以下检查（优先渲染为图片/PDF 后逐页视觉核验）：
  - [ ] 基于 `resources/PPT模板1.pptx` 原生母版与版式制作，未擅自换模板或整页重绘替代。
  - [ ] 全篇无任何 `Source` 字样或多余模板占位符/素材目录页。
  - [ ] 版式丰富美观、视觉层次清晰，适当复用了模板 1 的原生版式与内置图标/学院信息图，并按需补充融合了模板 2、3 的样式与素材。
  - [ ] 视觉检查文字清晰可读，无溢出、截断、重叠或遮挡。
  - [ ] 已在当前项目的 `exports/` 目录提供最终可编辑 `.pptx`。
